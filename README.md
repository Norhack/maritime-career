# Maritime Career Intelligence

Foundation skeleton for collecting, analyzing, and serving maritime career data.

## Milestone 1
- Repository structure
- FastAPI health and jobs endpoints
- Streamlit dashboard placeholder
- Docker and Docker Compose setup
- Requirements and lint configuration
- Scheduler stub
- CI workflow placeholders

## Local development
```bash
pip install -r requirements/dev.txt
uvicorn backend.main:app --reload
streamlit run dashboard/app.py
```
